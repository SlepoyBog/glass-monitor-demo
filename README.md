# Glass Monitor Demo

Портфолио-версия Windows-приложения для учёта ресурса защитных стёкол лазерных труборезов.

## Задача

До внедрения показатели считывались и переносились вручную. На ежедневный подсчёт ресурса стёкол и количества изготовленной номенклатуры уходило около 30–60 минут.

Приложение автоматизирует наблюдение за интерфейсом станка, связывает показания с установленным стеклом и формирует локальные отчёты. Решение рассчитано на изолированную производственную сеть: данные и обновления можно переносить через USB-накопитель.

## Результат

- внедрение на двух рабочих местах;
- сокращение ручной работы примерно на 90%;
- экономия порядка 10–20 часов в месяц;
- локальное хранение данных без обязательного подключения к интернету;
- выгрузка CSV/XLSX и проверка целостности пакетов;
- обработка смены задания и сброса счётчика;
- самопроверки логики и интерфейса.

Цифры основаны на фактическом рабочем процессе и пока не подтверждены отдельным хронометражным исследованием.

## Технологии

PowerShell 5.1, WinForms, Windows OCR, Open XML, CSV/JSON, SHA-256.

## Состав репозитория

- `src/GlassMonitor.ps1` — основное приложение и встроенные самопроверки;
- `src/ExcelReport.ps1` — автономное формирование XLSX;
- `tests/Test-Offline.ps1` — проверка офлайн-комплекта;
- `assets/monitor-icon.png` — ресурс интерфейса.

## Проверка

На Windows 10/11 с Windows PowerShell 5.1:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\GlassMonitor.ps1 -SelfTest
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\GlassMonitor.ps1 -CenteringSelfTest
```

Основной режим зависит от Windows OCR и от интерфейса промышленной программы, поэтому без целевой среды демонстрируется через код и встроенные тесты.

## Безопасность публикации

Это обезличенная версия. Номера станков заменены на `A01` и `B02`; производственные базы, отчёты, фамилии операторов, реальные пути и архивы не публикуются. Исходный рабочий проект остаётся приватным.

## Статус

Проект используется как пример прикладной автоматизации производственного процесса. Публичная версия предназначена для просмотра архитектуры и подхода к тестированию, а не для установки на реальное оборудование без адаптации.
